# Repository instructions

## Agent skills

### Issue tracker

Use local Markdown tickets. Before creating, reading, or updating
tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the default five triage roles. Before triaging tickets, read
`docs/agents/triage-labels.md`.

### Domain docs

This repository has a single domain context. `CONTEXT.md` is the
authoritative glossary. Before domain exploration or terminology
changes, read `docs/agents/domain.md`.

### Topic workflow

Before planning or executing a v2 topic, read
`tmp/edai2-plan/execution-v2/README.md` and its linked topic brief.
Follow their planning and execution rules. The roadmap remains
the sole topic-level status board; keep each topic's current
plan in its existing brief.
